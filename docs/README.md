# Docs

[`threat-landscape.md`](threat-landscape.md) lists the 11 risks at the MCP and tool layer that the rubric is built on. Each has a plain description of what goes wrong and an example. Examples marked Real link to a source. Examples marked Realistic are scenarios, not incidents.

It was checked against the MCP specification (2025-11-25) and OWASP Top 10 for LLM Applications (2025) on 14 October 2026. Re-check before relying on any detail.
