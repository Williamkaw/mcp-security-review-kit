# Templates

Three documents that surround a review. Use them in this order.

| File | Used by | When |
|---|---|---|
| [`intake-form.md`](intake-form.md) | The team requesting the server | Before the review starts |
| [`data-flow-diagram.md`](data-flow-diagram.md) | The reviewer | While gathering evidence, before scoring Prompt Injection Exposure |
| [`approval-checklist.md`](approval-checklist.md) | The reviewer and approvers | From evidence gathering to sign-off |

The decision record itself is [`../reviews/TEMPLATE.md`](../reviews/TEMPLATE.md).
